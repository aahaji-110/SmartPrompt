# مولّد البرومتات الاحترافية — 3dyat SmartPrompt

موقع عربي لتوليد البرومتات الإنجليزية الاحترافية (صور، فيديو، مجسمات 3D، برمجة ألعاب وتطبيقات، أغاني، كتابة، تعليق صوتي) يعمل على **Cloudflare Pages + Cloudflare D1 + Gemini AI**.

---

## المميزات
- **توليد حقيقي بالذكاء الاصطناعي (Gemini AI)** مع دعم رفع الصور التقريبية + نظام قوالب احتياطي تلقائي.
- **تسجيل دخول بالإيميل** لكل مستخدم مع قاعدة بيانات جاهزة للتطوير المستقبلي للباقات المدفوعة (`plan: free | pro`).
- **لوحة تحكم للأدمن (`/admin.html`)** محمية بكلمة مرور:
  - عرض **آخر 5 برومتات** (للأدمن فقط) مع إيميل المستخدم، المدينة والدولة، القسم، الفكرة، والبرومت جاهز للنسخ.
  - **إدارة البنر الإعلاني** مع إمكانية رفع صورة البنر مباشرة من جهازك وتحديث الموقع فوراً بدون تعديل الكود.
  - **جدول المستخدمين المسجلين** مع تصدير الإيميلات كملف CSV.
- **إحصائيات مباشرة سريعة** محفوظة في Cloudflare D1 بدون ضغط على الخدمات الخارجية.
- **زر تبديل الوضع الليلي/النهاري** + وسوم Open Graph للمشاركة في واتساب ومنصة X.

## خطوات النشر المجاني على Cloudflare Pages (5 دقائق)

### 1. إنشاء قاعدة بيانات D1 مجانية
1. ادخل على [Cloudflare Dashboard](https://dash.cloudflare.com/) وسجّل بحسابك المجاني.
2. من القائمة الجانبية اختر **Storage & Databases** → **D1 SQL Database** → **Create**.
3. سمّها `smartprompt-db` واضغط **Create**. *(الجداول تُنشأ تلقائياً عند أول زيارة للموقع!)*

### 2. ربط مستودع GitHub بـ Cloudflare Pages
1. من القائمة الجانبية اختر **Workers & Pages** → **Create** → تبويب **Pages** → **Connect to Git**.
2. اختر مستودع `aahaji-110/SmartPrompt` ثم اضغط **Begin setup**.
3. اترك **Build command** فارغاً، و **Build output directory** فارغاً (أو `.`) واضغط **Save and Deploy**.

### 3. ربط قاعدة البيانات وإضافة المتغيرات السرية
بعد أول نشر، افتح مشروعك في Cloudflare Pages → **Settings**:

1. **ربط قاعدة البيانات (Bindings):**
   - ادخل **Bindings** → **Add** → **D1 database**
   - **Variable name:** `DB`
   - **D1 database:** اختر `smartprompt-db` ثم احفظ.

2. **المتغيرات السرية (Variables and Secrets):**
   أضف المتغيرات التالية (اختر Encrypt / Secret):
   - `ADMIN_PASSWORD`: كلمة مرور قوية لدخول لوحة الأدمن `/admin.html`.
   - `GEMINI_API_KEY`: مفتاح مجاني من [Google AI Studio](https://aistudio.google.com/apikey) لتفعيل الذكاء الاصطناعي الحقيقي وقراءة الصور.
   - `SESSION_SECRET` *(اختياري)*: نص عشوائي طويل لتوقيع جلسات المستخدمين.

3. **إعادة النشر (Retry deployment):**
   من تبويب **Deployments** اضغط النقاط الثلاث بجانب آخر نشر → **Retry deployment** عشان تتفعّل المتغيرات وقاعدة البيانات.

### 4. رابط لوحة الأدمن
افتح: `https://your-site.pages.dev/admin.html` وسجّل دخولك بكلمة مرور `ADMIN_PASSWORD`.
